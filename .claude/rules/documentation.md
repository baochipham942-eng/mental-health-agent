# 文档规则

## 语言规范

- 所有 AI 回复、代码注释、文档必须使用**中文**
- 实施计划、思维链展示必须全中文编写
- 变量名和代码标识符使用英文

## 增量更新原则

- 除非信息已过时，否则**保留**之前的分析、截图记录和避坑指南
- Agent 记忆有限，文档是唯一的真理来源，丢失细节等于丢失项目上下文
- 对于计划变更或废弃的项目，**严禁直接删除**，必须使用删除线标识并说明原因

## 文档结构

**根目录仅保留核心身份文件**：
- `README.md` — 项目入口与快速开始
- `PROJECT_CONSTITUTION.md` — 项目宪法与核心原则
- `PROJECT_SUMMARY.md` — 项目全貌与当前状态概览
- `ARCHITECTURE.md` — 核心架构设计

**其他文档一律放入 `docs/`**：
- 变更日志、操作手册、设计文档、临时记录等

## 用户可见文案规范

用户界面中的禁用词：
- 咨询 → 对话/聊天
- 心理咨询 → 聊聊
- 咨询师 → 我（第一人称）
- 疗愈 → 成长
- PHQ-9 抑郁评分 → 情绪健康度
- GAD-7 焦虑评分 → 压力指数
- 心理评估 → 深度了解
- 症状 → 状态

后台代码和系统提示词中允许使用专业术语。
