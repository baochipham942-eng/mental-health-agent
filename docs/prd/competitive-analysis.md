## 关键洞察

### 1. 用户厌恶医疗标签

**数据支撑**：
- Woebot 用户评论高频词：`clinical`、`feels like a doctor`、`too structured`
- Pi 用户评论高频词：`like talking to a friend`、`natural`、`relaxing`

**结论**：用户想要的是"朋友"，不是"医生"。即使需要专业帮助，也希望在轻松氛围中获得。

### 2. 评估功能的正确打开方式

| 做法 | 用户感受 | 留存影响 |
|------|---------|---------|
| 首屏弹 PHQ-9 问卷 | "在被诊断" | 大幅降低 |
| 聊了几轮后温和建议 | "对方关心我" | 提升 |
| 用户主动触发 | "我想了解自己" | 最高 |

**结论**：评估应该是 Layer 2-3 功能，不是首屏入口。

### 3. Onboarding 的黄金法则

- **Pi**: 零选择，直接聊。首消息 < 3 秒看到。
- **Tolan**: 一个简单的名字输入，然后直接聊。
- **Woebot**: 7 步引导 → 用户在第 3 步流失。

**结论**：Onboarding 越少越好。"选择治疗师"这个动作本身就在强化"我在看心理医生"。

### 4. 功能渐进暴露（Progressive Disclosure）

最佳实践（从 Tolan + Flourish 提炼）：
```
首次打开 → 直接聊天（Layer 0）
↓ 聊了 2-3 轮
→ 自然推荐呼吸练习（Layer 1）
↓ 用户主动探索
→ 提供深度自我了解（Layer 2）
↓ 连续多次涉及同类情绪
→ AI 温和建议评估（Layer 3）
```

## 定位决策

### Before (v1)
```
心灵树洞 — AI心理咨询
├── 首屏选治疗师
├── "做个评估"直接触发 PHQ-9
├── UI 充满"咨询"、"疗愈"、"症状"
└── 用户感觉：我在看心理医生
```

### After (v2)
```
心灵树洞 — 你的解压搭子
├── 直接聊天，随机分配风格
├── 连续同类话题 3+ 次 → AI 温和建议了解自己
├── UI 全是"对话"、"聊天"、"成长"
└── 用户感觉：在跟朋友聊天
```

### 核心原则

> **改表不改里**：产品表面 = 解压搭子 | 产品底层 = CBT 专业咨询师

专业能力是核心竞争力，但用户不需要知道这些。就像好的餐厅不会在菜单上写食品安全检测报告。
